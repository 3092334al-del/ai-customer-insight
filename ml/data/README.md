## Открытый корпус

Русские ресторанные отзывы SentiRuEval-2015 вошли в SemEval-2016 Task 5 (Aspect Based Sentiment Analysis, домен Restaurants, язык Russian) в формате XML SE-ABSA16. Скачивание — со страницы задания https://alt.qcri.org/semeval2016/task5/ (раздел Data and Tools; может потребоваться регистрация на META-SHARE). Обучающий и тестовый файлы положите в `raw/`, например `raw/train.xml` и `raw/test.xml`.

Перевести в единый формат CSV (чтобы посмотреть глазами):

```bash
python -m aci_ml.dataset data/raw/train.xml data/semeval_train.csv
```

Лицензия корпуса — для исследовательских целей; в отчёте укажите источник.

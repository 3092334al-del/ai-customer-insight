# AI-Customer Insight

Учебный проект программы «Сириус.Лето» (партнёр — СПбГЭУ): анализатор отзывов для малого бизнеса. Владелец кафе загружает CSV с отзывами и видит тональность, категории жалоб, подтверждающие цитаты и план действий на 30 дней.

## Что умеет сейчас

- загрузка CSV (UTF-8 или Windows-1251 из Excel; разделитель `;`, `,` или табуляция);
- тональность: позитив / нейтрально / негатив;
- категории: сервис, качество еды, цена, атмосфера; отзыв без признаков попадает в «Прочее»;
- сильные стороны, зоны роста с числовым обоснованием, примеры отзывов, план улучшений.

Файл обрабатывается в браузере и не отправляется на сервер. Колонка с именами авторов не читается. Условия использования и конфиденциальность — в `dist/legal.html`.

## Публикация

Сайт — статические файлы из `dist/`. Их публикует на GitHub Pages workflow `.github/workflows/pages.yml` после каждого изменения ветки `main`, если тесты прошли. Для нового репозитория один раз включите: Settings → Pages → Source: GitHub Actions.

## Как устроен анализ (модель 0)

`dist/analyzer.js` — словарная модель: ищет в отзыве слова-признаки (основы слов из списков), учитывает приставку и частицу «не», а также оценку гостя. Это точка отсчёта для сравнения с моделями TF-IDF + логистическая регрессия и rubert-tiny2, которые обучаются на размеченных отзывах.

Известные ограничения: не понимает иронию, двойное отрицание и смешанные отзывы. Примеры — в `test/analyzer.test.mjs`.

## Структура

| Файл | Что делает |
|---|---|
| `dist/index.html`, `dist/*.css` | интерфейс |
| `dist/app.js` | отрисовка дашборда и рекомендаций |
| `dist/analyzer.js` | модель 0: тональность и категории |
| `dist/csv.js` | чтение CSV: кодировка, колонки, даты |
| `server.js` | локальный сервер для разработки |
| `test/` | тесты (`node --test`) |
| `ml/` | Python: обучаемые модели, разметка, API (см. `ml/README.md`) |

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm start
```

Сайт откроется на `http://localhost:3000`. Открыть `index.html` двойным щелчком не получится: браузер не загружает модули с `file://`.

```bash
npm test
```

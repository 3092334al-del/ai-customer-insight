# AI-Customer Insight

Функциональный веб-прототип интеллектуального анализатора отзывов для малого бизнеса.

## Возможности

- загрузка CSV с автоматическим определением `;` или `,`;
- нормализация колонок автора, даты, оценки и текста;
- классификация тональности и четырёх аспектов;
- интерактивный дашборд, поиск и фильтрация;
- приоритетные жалобы и рекомендации;
- экспорт обогащённого CSV;
- обработка данных только в браузере.

Откройте `dist/index.html` или используйте опубликованную версию Site.

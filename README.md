# AI-Customer Insight

Веб-сервис для анализа клиентских отзывов малого бизнеса. Пользователь вставляет ссылку на карточку компании в Яндекс Картах или загружает CSV, а система показывает тональность, обсуждаемые аспекты, сильные стороны, зоны роста, подтверждающие цитаты и план действий на 30 дней.

## Возможности

- импорт до 50 доступных публичных отзывов по ссылке Яндекс Карт;
- загрузка CSV с колонками текста, оценки, даты и автора;
- анализ семи аспектов: сервис, качество, цена, комфорт, удобство, надёжность и общее впечатление;
- отдельные сильные стороны и зоны роста с числовым обоснованием;
- примеры отзывов, подробная оценка аспектов и приоритетный план улучшений.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm start
```

После запуска сайт доступен на `http://localhost:3000`, проверка состояния — на `/health`.

```bash
npm test
```

## Ограничение импорта

Яндекс Карты не предоставляют открытую официальную API для полной выгрузки отзывов. Сервис обрабатывает только отзывы, которые присутствуют в публичной серверной версии страницы, не обходит CAPTCHA и другие ограничения площадки. Если импорт по ссылке недоступен, можно использовать CSV.
